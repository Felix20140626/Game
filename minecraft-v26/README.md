# 我的世界 v26.1 - 网页联机版

一个基于浏览器的 Minecraft 风格沙盒游戏，支持多人在线联机。

## 🎮 游戏特性

- **版本**: 26.1
- **26 种方块**: 包括草方块、石头、矿石、特殊方块等
- **程序化世界生成**: 包含地形、洞穴、矿脉、树木
- **多人联机**: 支持多名玩家同时在线游戏
- **实时聊天**: 内置聊天系统
- **物理系统**: 玩家移动、跳跃、碰撞检测
- **3D 渲染**: 使用 Three.js 进行高效渲染

## 📦 安装步骤

### 1. 确保已安装 Node.js

```bash
node --version  # 需要 v14 或更高版本
```

### 2. 安装依赖

```bash
cd minecraft-v26
npm install
```

### 3. 启动服务器

```bash
npm start
```

### 4. 访问游戏

打开浏览器访问：http://localhost:3000

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| W/A/S/D | 前后左右移动 |
| 空格 | 跳跃 |
| 鼠标移动 | 控制视角 |
| 左键点击 | 破坏方块 |
| 右键点击 | 放置方块 |
| 数字键 1-9 | 选择快捷栏方块 |
| T / Enter | 打开聊天 |
| ESC | 打开菜单 |
| F3 | 显示/隐藏调试信息 |

## 🌐 多人联机

### 局域网联机

1. 主机启动服务器
2. 其他玩家访问主机的 IP 地址：`http://[主机IP]:3000`

### 公网联机

需要使用内网穿透工具或将服务器部署到公网服务器。

## 📁 项目结构

```
minecraft-v26/
├── public/                 # 前端文件
│   ├── index.html         # 游戏页面
│   └── js/                # JavaScript 模块
│       ├── blocks.js      # 方块定义 (26 种)
│       ├── world.js       # 世界生成
│       ├── player.js      # 玩家系统
│       ├── worldManager.js # 世界管理
│       ├── renderer.js    # 3D 渲染
│       ├── network.js     # 网络通信
│       └── game.js        # 游戏主逻辑
├── server.js              # Node.js 服务器
├── package.json           # 项目配置
└── README.md             # 说明文档
```

## 🔧 技术栈

- **前端**:
  - Three.js (3D 渲染)
  - Socket.IO Client (网络通信)
  - HTML5/CSS3
  
- **后端**:
  - Node.js
  - Express (Web 服务器)
  - Socket.IO (实时通信)

## ⚙️ 配置选项

在 `public/index.html` 中可以修改游戏配置：

```javascript
game.init({
    multiplayer: false,     // 是否启用多人模式
    username: 'Player',     // 玩家名称
    seed: null,            // 世界种子 (null 为随机)
    renderDistance: 4      // 渲染距离 (区块数)
});
```

## 🐛 已知限制

- 由于是网页版，性能受限于浏览器
- 世界大小有限制 (256x256x128)
- 部分高级功能尚未实现（如红石、生物等）
