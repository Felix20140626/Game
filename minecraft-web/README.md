# Minecraft Web Edition v26.1

一个基于浏览器的我的世界风格游戏，支持多人联机。

## 功能特性

- ✅ 版本 26.1
- ✅ 多人联机支持
- ✅ 3D 方块世界
- ✅ 玩家移动和跳跃
- ✅ 放置和破坏方块
- ✅ 实时聊天系统
- ✅ 玩家列表显示
- ✅ 5 种方块类型（草地、泥土、树叶、石头、黄金）

## 快速开始

### 安装依赖

```bash
cd minecraft-web
npm install
```

### 启动服务器

```bash
npm start
```

### 访问游戏

在浏览器中打开：http://localhost:3000

## 操作说明

- **WASD** - 移动
- **空格键** - 跳跃
- **鼠标** - 视角控制
- **左键点击** - 破坏方块
- **右键点击** - 放置方块
- **数字键 1-5** - 选择方块类型
- **Enter** - 发送聊天消息
- **ESC** - 退出鼠标锁定

## 技术栈

- **后端**: Node.js + Express + Socket.IO
- **前端**: Three.js (3D 渲染)
- **通信**: WebSocket (实时联机)

## 多人联机

1. 启动服务器后，多个玩家可以通过访问 `http://你的IP:3000` 加入同一局游戏
2. 所有玩家的位置、方块操作和聊天消息都会实时同步
3. 玩家列表中会显示所有在线玩家

## 注意事项

- 需要现代浏览器支持 WebGL
- 建议使用 Chrome、Firefox 或 Edge 浏览器
- 首次加载可能需要几秒钟时间
